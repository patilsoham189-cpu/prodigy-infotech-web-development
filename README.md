# Prodigy InfoTech — Web Development Internship Projects

This repository consolidates the frontend web applications and interactive projects completed during the **Web Development Internship at Prodigy InfoTech**.

---

## 🚀 Projects Overview

| Task | Project | Tech Stack | Description |
| :---: | :--- | :--- | :--- |
| **01** | [**GameHub — Landing Page**](./task-01-landing-page/) | HTML5, CSS3, Flexbox | A responsive modern gaming hub landing page featuring featured games, dynamic cards, and newsletter signup. |
| **02** | [**Interactive Stopwatch**](./task-02-stopwatch-app/) | HTML5, CSS3, JavaScript | A precision stopwatch web app supporting start, pause, lap-timing recording, and reset controls with animated UI. |
| **03** | [**Tic-Tac-Toe Game**](./task-03-tic-tac-toe/) | HTML5, CSS3, JavaScript | Classic two-player interactive Tic-Tac-Toe game featuring real-time win detection, draw alerts, and turn indicators. |
| **05** | [**Weather Forecast App**](./task-05-weather-app/) | HTML5, CSS3, JavaScript, OpenWeather API | Dynamic real-time weather tracker with city search, geolocation support, and 5-day weather forecast cards. |

---

## 🛠️ Technologies Used
- **Languages:** HTML5, CSS3, JavaScript (ES6+)
- **Concepts:** DOM Manipulation, Asynchronous JavaScript (Fetch API, Promises), Flexbox & CSS Grid, Event Handling, Local Storage
- **External APIs:** OpenWeatherMap API
